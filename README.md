# 蟻級單元導航模擬器(ant_sim)

以「蟻級單元」凍結規格為藍本的 2D 模擬器與機上演算法。目的:在買零件之前,
把演算法階梯的第 1–5 階在**誠實的雜訊**下跑通,並把每一個門檻與教訓帶到實機。

**鐵律:`brain.py` 是未來 ESP32-S3 韌體的 1:1 藍本,只准讀 `SensorPacket` 與
相機影像,嚴禁引用任何真值。** 真值只交給實驗腳本當裁判(= 天花板相機的角色)。

## 快速開始

```bash
pip install numpy matplotlib        # 只需要這兩個
python3 smoke_test.py               # 校定工具:符號、FFT、門檻表、打滑統計
python3 experiments/exp1_homing.py  # 中央覓食五趟,四配置對打(~3 分鐘)
python3 experiments/exp2_compass.py # 航向時間線 + 關燈時段(秒級)
python3 experiments/exp3_catchment.py # 快照歸巢集水區地圖(~1 分鐘)
python3 experiments/exp4_route.py   # 熟悉度循路回放(秒級)
python3 make_demo.py                # 錄一趟完整任務成 GIF
```

圖與資料輸出到 `out/`。

## 演算法階梯對應

| 階 | brain.py 類別 | 一句話 |
|---|---|---|
| 1 | `Controller`(三相繞行)、`Forager`(OU 隨機遊走) | Braitenberg 式反射與覓食 |
| 2 | `HeadingBank` + `PathIntegrator` + `Homer` + `SearchSpiral` | 箭蟻回家向量 + Wehner 系統性搜尋 |
| 3 | `ridf()` 視覺羅盤(FFT 圓周相關,0.07 ms/次) | 巢錨定絕對航向 |
| 4 | `SnapshotHomer`(run-and-tumble 沿 IDF 梯度) | Cartwright–Collett / Zeil 快照歸巢 |
| 5 | `RouteFollower`(完美記憶版熟悉度) | Baddeley 2012 的基準線 |

## 實驗結果(本版實測)

**實驗一・中央覓食五趟**(每趟覓食 25 s 後歸巢;n=12;到家誤差中位數 cm):

| 配置 | 趟1 | 趟2 | 趟3 | 趟4 | 趟5 |
|---|---|---|---|---|---|
| A 純編碼器 | 93 | 128 | 126 | 124 | 158 |
| B +陀螺 | 8.7 | 8.9 | 12.3 | 17.1 | 21.5 |
| C +巢錨定視覺 | 5.2 | 4.6 | 4.1 | 5.1 | 5.3 |
| D C+光流打滑抑制 | 5.0 | 4.7 | 6.0 | 5.5 | 3.8 |

打滑判編碼器死刑;陀螺短期漂亮但溫漂逐趟複利;視覺錨定把誤差**壓平**在
視覺鎖半徑(~5 cm)。C≈D 是因為靠泊精度由鎖半徑決定;光流的價值在著陸
距離與搜尋時間(打滑重的個體差異上)。

**實驗二・航向時間線(關燈 30–55 s)**:最大|航向誤差| enc/gyro/fused =
關燈前 31.5/1.3/1.9°、關燈中 73.7/3.5/1.4°(fused 靠陀螺優雅退化)、
復燈後 130/15.2/5.0°(fused 於 77 s 鎖巢瞬間彈回)。

**實驗三・快照歸巢集水區**(71 起點、50 s 逾時):總成功率 35%,但空間結構
才是重點——起點距巢 0–0.5 m 成功 85%、0.5–1 m 47%、1–1.6 m 21%、更遠 9%;
成功案例最終距離中位數 3.5 cm。**快照歸巢是半徑約 0.8–1 m 的區域技能**
(Zeil 2003),這正是階 5 的存在理由。

**實驗四・循路回放**(31 張視圖、8 cm 間距,記憶體 ~93 KB):
路上起步平均偏差 2.4 cm(max 6.1);+14 cm 側偏起步 13.3 cm;
−17 cm、+20° 航向偏移起步 18.0 cm——三者皆到達終點。

## 五條實戰教訓(每條都是被模擬器擊斃後驗屍得來)

1. **小場地沒有「遠方」。** 單一快照的絕對羅盤在 2×3 m 場地的有效半徑只有
   6–10 cm(位移 10 cm 誤差 +8.7°)。視差不是雜訊,是物理。→ 羅盤改為
   **巢錨定**:只在視覺確認到巢時錨定航向並把 PI 歸零(螞蟻本來就這麼做)。
2. **搜尋幾何會跟自己的感測防線打架。** 螺旋轉太快觸發陀螺閘控擋掉所有幀;
   開環螺旋還會漂移、把巢留在盲區。→ 搜尋降速換小迴轉半徑,且**用 PI 閉環**
   繞「相信的巢」畫擴張同心圈(Wehner 沙漠螞蟻的搜尋幾何)。
3. **光照增益漂移 ±5% 就淹掉在完美燈況校定的門檻。** 症狀是「第一趟成功、
   之後全滅」。→ 所有匹配前做**光度正規化**(零均值/單位變異),門檻用
   正規化單位重校。
4. **牆面天際線是準週期的,會給出自信但大錯的角度。** 羅盤閘門在牆邊漏氣,
   一趟之內把航向毒到 +47°,PI 跟著毒出「幽靈巢」。→ 視覺角度必須與陀螺
   先驗一致(±30°)才准融合;鎖巢判定(旋轉不變)從融合閘解耦。
5. **P 控制器 + 單純反射 = 圓筒死鎖。** 反射轉開、控制器立刻轉回去撞,無限
   循環。→ 觸鬚反射改三相:倒退轉開 → **直走繞行 1 秒**打破對稱 → 還控制權。

門檻總表(正規化單位;`smoke_test.py` 可重新量測):
羅盤帶域近距 `COMPASS_NEAR=0.60`(≈6 cm)、鎖巢全圖 `NEST_LOCK_FULL=0.060`
(≈6 cm)、快照到家 `0.040`(≈4–5 cm)、RIDF 信心 `0.22`(關燈時實測 0.05)、
陀螺一致性 `±30°`、陀螺閘控 `80°/s`。

## 實機校定手冊(對應 smoke_test 的四段)

1. 機器人置於巢、面向 0°:原地轉已知角度(±10/30/80°),驗 RIDF 符號與精度、
   量 conf 的正常值域。
2. 已知小位移(3/6/10/20 cm,用尺):量帶域 min-SSD 與全圖 IDF → 填三個門檻。
3. 關燈一次:確認 conf 掉到門檻以下。
4. 混合行駛 20 s 對照天花板相機:量你家地墊的實際打滑水準,回填 config。

## 韌體移植路徑(ESP32-S3)

- **Core 0(200 Hz)**:`HeadingBank.on_packet`、`PathIntegrator.on_packet`、
  `Controller.mix`、PID 與安全 —— 全是每步幾十次浮點運算,負載個位數 %。
- **Core 1(12–15 fps)**:取像 → 查表展開 64×48 → 正規化 → `ridf`/`img_diff`。
  FFT 用 esp-dsp 的 `dsps_fft2r_fc32`(64 點 × 48 列);Python 版 0.07 ms/次,
  ESP32-S3 估 1–3 ms/次,15 fps 綽綽有餘。
- **記憶體**:視圖 3 KB/張;循路 31 張 = 93 KB,PSRAM(8 MB)可放 80 倍長的路線。
- 類別 → 模組對應:`SensorPacket`=序列上行封包結構、`HeadingBank`=heading.cpp、
  `PathIntegrator`+`SearchSpiral`=pi.cpp、`SnapshotHomer`=snapshot.cpp、
  `RouteFollower`=route.cpp。演算法邏輯逐行對翻即可,因為本來就沒用到真值。

## 已知限制與下一步

- 成像是剪影模型(黑物體/亮背景的聯集),沒有紋理與鏡面反射;實機的球面鏡
  展開需另做查表校正(棋盤或已知圓筒法)。
- 光流只模擬前向分量;實機 PAA5100 有二軸,側滑可另用。
- 下一階:階 6 環吸引子(把 `HeadingBank` 換成神經元環)、階 7 多機費洛蒙
  (天花板相機當虛擬費洛蒙網格,已預留裁判介面)。
